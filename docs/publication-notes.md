# Publication and provenance

This portfolio copy was prepared after the course work. Documentation, audit
tables, validation notes and synthetic examples are new portfolio additions;
they are not claimed as original course deliverables. Original files were
preserved. This repository starts with a new Git history.

This was a team project. The owner's contribution is identified in the README;
other team members' reports, annotations and framework work are not represented
as the owner's independent work. No new open-source license has been assigned
to team code or third-party materials. Existing dependency licenses remain
with their respective projects.

Excluded: virtual environments, IDE settings, caches, local paths, credentials,
raw course videos/images/annotations, course documents, archives, model weights,
and unrelated or superseded scripts. Rights to redistribute the course data
could not be confirmed. Obtain it from the course team with permission.
